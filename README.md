## Featured Work

### AI Document Intelligence — Pfizer
Worked on an end-to-end AI document intelligence workflow for pharmaceutical supply-chain documents.

- Benchmarked **Tesseract** and **PaddleOCR** for automated text extraction
- Built a context-aware **Retrieval-Augmented Generation (RAG)** pipeline with **LlamaIndex**
- Integrated extraction, classification, retrieval, and evaluation into a complete document-processing workflow

### GreenGain — HackEarth Best Sustainability Impact Award
A web application that turns **IRS Form 5695** tax-credit rules into a personalized sustainability roadmap.

- Built a modular **Next.js + React + Tailwind CSS** frontend
- Developed a state-driven tax-credit estimator for personalized recommendations

- Collaborated with stakeholders through sprint reviews and weekly milestone tracking
